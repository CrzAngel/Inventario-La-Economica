# Inventario La Económica

Sistema web de inventario desarrollado para el Supermercado La Económica.

## Descripción

Este proyecto permite administrar productos, categorías, proveedores y movimientos de inventario.

El sistema registra entradas y salidas de productos y actualiza automáticamente el stock disponible.

## Funcionalidades

- Inicio de sesión
- Dashboard
- Gestión de productos
- Gestión de categorías
- Gestión de proveedores
- Búsqueda de productos
- Entradas de inventario
- Salidas de inventario
- Control automático de stock
- Validación de stock disponible
- Reporte general de inventario
- Reporte de productos con stock bajo
- Reporte de movimientos
- Impresión de reportes
- Cierre de sesión

## Tecnologías utilizadas

- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- HTML
- CSS
- JavaScript
- Visual Studio

## Base de datos

El sistema utiliza SQL Server mediante Entity Framework Core.

Base de datos:

`InventarioLaEconomicaDB`

Principales tablas:

- Productos
- Categorias
- Proveedores
- MovimientosInventario
